Docusaurus Classicの機能を体験

備考

このページではClassicのドキュメント機能を試せます。サイト内検索はClassic本体の標準機能ではなく追加テーマを使用しています。Mermaidも公式の追加テーマです。

1. ナビゲーションと言語​

  • 上部メニューの한국어 / 日本語で言語を切り替えます。
  • 左側のカテゴリ別サイドバーから文書を開きます。
  • 右側の目次で見出しへ移動します。
  • パンくずリスト、前・次ページのリンク、ダークモードも確認します。
  • 画面上部のお知らせバーは閉じられます。

2. 注意書き​

ヒント

長い技術文書では、最初に要点を示すと理解しやすくなります。

注意

教材の例を本番環境にそのまま適用しないでください。

危険

個人情報、APIキー、非公開の認証情報を公開しないでください。
