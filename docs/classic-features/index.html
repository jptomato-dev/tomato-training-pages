Docusaurus Classic 기능 체험

정보

이 페이지는 Classic 문서 기능을 확인하기 위한 예제입니다. 로컬 검색은 Classic에 기본 포함되지 않으며 별도 테마를 추가합니다. Mermaid도 공식 확장 테마를 사용합니다.

1. 문서 탐색과 언어​

  • 상단의 언어 메뉴에서 한국어 / 日本語를 전환합니다.
  • 왼쪽의 카테고리별 사이드바에서 문서를 선택합니다.
  • 오른쪽 목차에서 현재 페이지의 소제목을 선택합니다.
  • 상단의 경로(Breadcrumb), 페이지 하단 이전/다음 이동도 확인합니다.
  • 상단 다크 모드 버튼과 공지 배너 닫기를 시험합니다.

2. 안내 상자(Admonitions)​

팁

긴 기술 문서는 요약을 먼저 제공하면 이해하기 쉽습니다.

주의

교육용 예제를 실제 운영 환경에 그대로 적용하지 마세요.

위험

개인정보, API 키, 비공개 자격증명은 공개 문서에 넣지 않습니다.

3. 언어별 코드 탭 (MDX)​

  • PowerShell
  • Bash
Windows PowerShell
Write-Output "Hello TOMATO"
Bash
echo "Hello TOMATO"

4. 코드 강조 및 복사 버튼​

example.py
def greet(name: str) -> str:
    return f"Hello, {name}!"

print(greet("TOMATO"))

5. 표와 각주​

기능기본 제공 여부확인 방법
제목 / 목차Classic오른쪽 TOC
코드 강조 / 복사Classic위 코드 블록
경고 박스Classic위 안내 상자
코드 탭Classic + MDX위 탭
검색추가 로컬 검색 테마상단 검색창
Mermaid공식 Mermaid 테마아래 다이어그램

문서 작성 표준은 별도 내부 파일에서 관리합니다.1

6. Mermaid 다이어그램​

7. 검색과 기타 기능​

상단 검색창에서 Copilot, GitHub, AWS 등으로 검색합니다. 검색은 정적 인덱스를 기반으로 작동하며, 동적 웹 검색 서비스는 사용하지 않습니다.

참고

버전별 문서, 블로그, 커스텀 React UI, 사용자 인증 등은 확장할 수 있지만 현재 교육 사이트의 범위에는 포함하지 않았습니다.
